# Rent Master - Car Rental Management System

A comprehensive desktop application designed to streamline car rental operations. Rent Master automates the process of vehicle registration, customer management, rental bookings, and return management, offering a user-friendly interface and improved operational efficiency for car rental businesses.


## Introduction

Rent Master addresses the inefficiencies in car rental management by providing a solution that automates and simplifies the process. From customer registration to vehicle availability tracking and rental fee management, this system ensures seamless operation for both small and medium-sized rental businesses.

## Features

- **User Management:** Secure login for administrators.
- **Vehicle Management:** Efficient vehicle registration and real-time availability tracking.
- **Customer Management:** Easy customer registration and profile management.
- **Booking Management:** Real-time updates on vehicle bookings, reducing conflicts.
- **Rental Process:** Automated check-in/check-out and return management.
- **Accurate Billing:** Pricing on rental duration, vehicle type, and any additional services.
- **Earnings Overview:** Track and analyze earnings over time.

## Technologies Used

- **Programming Language:** C# .NET
- **Database:** Microsoft SQL Server
- **GUI:** Windows Forms
